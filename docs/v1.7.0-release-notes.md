## [1.7.0] - 2026-11-03

### Added（新增）

- 参数写错时输出中文提示，替代原英文报错：
  - 参数缺少取值：提示该参数后面需要一个值，并给出示例写法；
  - 同一参数以不同大小写或缩写重复出现：提示二者为同一参数，只写一次即可；
  - 参数名不存在：提示最接近的正确参数名；
  - 参数取值超出允许范围：列出允许的取值。
  - 提示末尾附「运行 asq -h 查看完整参数说明」，退出码为 1。
- WorkBuddy 列表的 `-Credits` 与 `-ActualCredits` 可同时使用：并排显示两列，`Credits` 在左、`ActualCredits` 在右；只带其中一个时行为不变。

### Fixed（修复）

- 修复 WorkBuddy 积分列对「无积分记账条目」会话显示 `-` 的问题。
  - 修复前：会话有会话日志、但平台未生成积分记账条目（如全部请求使用免积分模型）时，列表与详情的积分列显示 `-`，与「无记录」不可区分。
  - 修复后：此类会话显示 `0.00`；子智能体行与无会话日志的会话仍显示 `-`；`-AsJson` 输出不变（无记录仍为 `null`）。
