## [1.7.1] - 2026-11-09

### Added（新增）

- 新增查询结果条数统计，列表与 `-c` 视图上、下各显示一行「共 M 条会话，本次列出 N 条」。
  - 未列全时在同一行补「参数 '-n M' 可显示全」；结果为 0 条时不显示该行。
- 新增按列表缩略号查看会话详情，`-s` 支持直接输入列表上的编号。

### Changed（变更）

- 列表会话编号改为普通会话显示前 8 位，子智能体显示 `ag-` 加 6 位（如 `ag-2046da`）。
