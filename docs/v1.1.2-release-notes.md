# AgentsSessionQuery v1.1.2 发布说明

> 本文件为 v1.1.2 的发布说明（Release Notes），内容格式遵循 [Keep a Changelog](https://keepachangelog.com/en/2.0.0/) 2.0.0 约定（中文场景采用「英文（中文）」双语类型标题），版本号遵循语义化版本（SemVer）。
> 与 v1.1.2 的提交信息及 CHANGELOG.md 的 `[1.1.2]` 段保持一致。

## [1.1.2] - 2026-09-07

### Fixed（修复）

- 采纳外部贡献者 [@liyangbing](https://github.com/liyangbing) 的路径匹配修复（来自社区 [PR #1](https://github.com/iuuunlyk/AgentSessionQuery/pull/1)，pull request（拉取请求））：`-IncludeSubdirectories`（`-r`）过滤原硬编码 Windows 反斜杠 `\`，在 macOS / Linux 下子目录匹配实际失效；改为以 `[System.IO.Path]::DirectorySeparatorChar` 对当前工作区与会话工作区路径做平台无关归一化（兼容 `AltDirectorySeparatorChar`）。**注意**：asq 仍仅面向 Windows 设计，本 PR 属防御性加固（避免在非 Windows 的 PowerShell 路径分隔符差异下静默失效），不表示已支持 macOS / Linux（详见 README「开发者说明」）。

### Changed（变更）

- 版本号改为单一真源：新增 `$ScriptVersion` 变量（当前 `v1.1.2`），`asq -h` 帮助文本的 `-v` 说明与 `-v` / `-Version` 输出均引用该变量；发版时仅改一处即可，消除此前三处硬编码版本字面易遗漏的问题。`asq -v` 现输出 `v1.1.2`。

## 升级说明（含破坏性变更）

- 本版本**无破坏性变更**，属缺陷修复（PATCH）与内部重构，不影响既有 `asq` 用法与查询结果。
- 本次路径分隔符归一化属防御性加固，asq 仍**仅面向 Windows 设计**；即便代码已对非 Windows 路径分隔符做兼容归一化，也不表示已支持 macOS / Linux（详见 README「开发者说明」），Windows 用户行为不变。
- 版本号说明：本次含一处缺陷修复，按 SemVer 定级 PATCH（v1.1.2）；破坏性变更仍按既定策略升次版本（MINOR），预留 v2.x 给可视化前端开发线。
- 致谢：路径匹配修复思路来自社区贡献者 [@liyangbing](https://github.com/liyangbing)（[PR #1](https://github.com/iuuunlyk/AgentSessionQuery/pull/1)），在此致谢。
