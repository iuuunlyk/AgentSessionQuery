# AgentsSessionQuery v1.0.0 发布说明

> 本文件为 v1.0.0 的发布说明（Release Notes），内容格式遵循 [Keep a Changelog](https://keepachangelog.com/en/2.0.0/) 2.0.0 约定（中文场景采用「英文（中文）」双语类型标题），版本号遵循语义化版本（SemVer）。
> 与 v1.0.0 的提交信息及 CHANGELOG.md 的 `[v1.0.0]` 段保持一致。

## [v1.0.0] - 2026-09-01

### Added（新增）

- 首次对公开发布 AgentsSessionQuery（asq）统一会话查询工具套件：整合 Codex / Claude / WorkBuddy 三条会话查询命令，并提供统一入口 `asq`（Agents Sessions Query）。
- 列表与模糊检索（`-q` / `-t`）、模型展示、可恢复命令（`-c` / `-s`）、脚本化 JSON 输出（`-AsJson`）、Token 统计（6 字段，与 token-monitor / tokscale 口径对齐）、三态数据源检测（未安装 / 已装未用 / 已用）。
- 统一命令 `asq` 与 PowerShell Profile 别名接入（`session-profile-aliases.ps1`）。

## 范围说明

- 本版本为首次公开发布，仅含发布相关文档与版本号对齐（套件发布版本定为 v1.0.0），不含功能性代码变更。
- 本工具为只读、零写入的本地会话查询工具：所有数据源经 `$HOME` 解析，可移植至任意装有 PowerShell 7 的 Windows 电脑。
- 历史版本（v0.x）发布说明与内部开发文档不随开源发布。
